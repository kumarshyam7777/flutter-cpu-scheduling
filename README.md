# Flutter CPU Scheduler

This is a Flutter port of the CPU Scheduling visualizer (FCFS, SJF, SRTF, RR). It includes a responsive UI, animated Gantt chart, and the scheduling logic.

Getting started

1. Install Flutter: https://flutter.dev/docs/get-started/install
2. From this folder run:

```bash
flutter pub get
flutter run
```

Notes

- The UI is in `lib/main.dart` and components are under `lib/widgets/`.
- Scheduling logic is in `lib/scheduler.dart`.
